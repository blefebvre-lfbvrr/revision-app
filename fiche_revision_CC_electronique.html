Conversion entre systemes numeriques
Binaire · Decimal · Hexadecimal

1.1 — Pourquoi plusieurs bases ?

Dans la vie quotidienne, on utilise le systeme decimal (base 10, chiffres 0 a 9). Les ordinateurs et microcontroleurs ne comprennent que deux etats electriques : tension haute (~5V) = 1, tension basse (0V) = 0. C'est le systeme binaire (base 2). Pour ecrire le binaire de facon plus compacte, on utilise le systeme hexadecimal (base 16).

1.2 — Le principe fondamental : position = puissance de la base

Decimal : 345 = 3x10² + 4x10¹ + 5x10° = 300+40+5 = 345 Binaire : 0b1101 = 1x2³ + 1x2² + 0x2¹ + 1x2° = 8+4+0+1 = 13 Hex : 0x2F = 2x16¹ + 15x16° = 32+15 = 47

MSB vs LSB : b7 est le bit de poids fort (MSB = Most Significant Bit, le plus a gauche). b0 est le bit de poids faible (LSB = Least Significant Bit, le plus a droite). Pour lire un mot binaire : on part de la droite, les poids doublent a chaque pas vers la gauche.

1.4 — Conversion Decimal vers Binaire : divisions successives par 2

On divise le nombre par 2, on note le reste (0 ou 1), on recommence avec le quotient. On s'arrete quand le quotient est 0. On lit les restes de bas en haut.

Exemple : 42 en decimal → binaire 8 bits
DivisionQuotientReste (bit)
42 ÷ 2210 ← b0
21 ÷ 2101 ← b1
10 ÷ 250 ← b2
5 ÷ 221 ← b3
2 ÷ 210 ← b4
1 ÷ 201 ← b5
Lecture de bas en haut : 101010. En 8 bits (completer avec des 0 a gauche) : 0b00101010
Verification : 32+8+2 = 42 ✓

1.5 — Conversion Binaire vers Decimal : sommer les poids

Exemple : 0b10010110 → decimal
= 1x128 + 0x64 + 0x32 + 1x16 + 0x8 + 1x4 + 1x2 + 0x1 = 128 + 16 + 4 + 2 = 150

1.6 — Le systeme hexadecimal : 1 chiffre hex = 4 bits

Decimal0123456789101112131415
Hex0123456789ABCDEF
Binaire0000000100100011010001010110011110001001101010111100110111101111

La propriete cle : comme 16 = 2^4, chaque chiffre hex correspond exactement a un groupe de 4 bits.

Exemple : 0b00101010 → hexadecimal
Separer en groupes de 4 bits (depuis la droite) : 0010 | 1010
0010 = 2 → 2
1010 = 8+2 = 10 → A
Resultat : 0x2A — Verification : 2x16+10 = 42 ✓
⚠️
Pieges frequents : (1) Oublier de completer a 8 bits avec des zeros a gauche. (2) Confondre A=10, B=11, C=12, D=13, E=14, F=15. (3) Grouper les bits par 4 en partant de la gauche au lieu de la droite (toujours partir de la droite).

1.8 — Methode universelle resumee

  1. Dec → Bin : Divisions successives par 2, noter les restes, lire de bas en haut. Completer a gauche avec des 0 pour atteindre 4 ou 8 bits.
  2. Bin → Dec : Multiplier chaque bit par sa puissance de 2, sommer. Utiliser la table : 128, 64, 32, 16, 8, 4, 2, 1.
  3. Bin → Hex : Grouper les bits par 4 en partant de la droite. Convertir chaque groupe avec la table.
  4. Hex → Bin : Remplacer chaque chiffre hex par ses 4 bits equivalents (utiliser la table).
  5. Dec → Hex : Passer par le binaire puis grouper par 4 (ou diviser par 16 avec la meme methode que par 2).

Fonctions logiques et Karnaugh
Portes elementaires · Tables de verite · Simplification · Circuits

2.1 — Qu'est-ce qu'une fonction logique ?

Une fonction logique prend des entrees binaires (0 ou 1) et produit une sortie binaire (0 ou 1). C'est la brique fondamentale de tout circuit numerique.

Fonctions combinatoires
La sortie depend uniquement des entrees actuelles. Pas de memoire. Exemples : AND, OR, additionneur.
Fonctions sequentielles
La sortie depend des entrees ET de l'etat precedent (memoire). Exemples : bascule D, compteur.

Le CC porte principalement sur les fonctions combinatoires.

2.3 — Construire une table de verite

Pour n variables d'entree : 2^n lignes. On enumere toutes les combinaisons (comme compter en binaire de 0 a 2^n-1), puis on calcule la sortie pour chaque ligne.

2.4 — De la table de verite a l'equation brute (somme de mintermes)

  1. Reperer toutes les lignes ou la sortie S = 1.
  2. Pour chaque ligne S=1 : ecrire le produit (AND) de toutes les variables. Variable = 1 dans cette ligne → on l'ecrit normale (A). Variable = 0 dans cette ligne → on l'ecrit complementee (A-barre).
  3. Faire la somme (OR) de tous ces produits → equation brute.

Cette equation est correcte mais souvent longue. On la simplifie avec Karnaugh.

2.5 — La simplification de Karnaugh

Le tableau de Karnaugh exploite la propriete booleenne fondamentale :

A.B + A.B-barre = A.(B+B-barre) = A.1 = A → Si deux cas donnent S=1 et ne different QUE par une variable, cette variable est eliminee.

Les regles d'or des regroupements

  • ✅ Tailles autorisees : 1, 2, 4 ou 8 cases uniquement (puissances de 2). Jamais 3, 5, 6, 7.
  • ✅ Formes : rectangles ou carres uniquement. Pas de diagonales, pas de L.
  • ✅ Le tableau est torique ("monde rond") : la colonne BC=10 (droite) est adjacente a BC=00 (gauche). La ligne A=1 (bas) est adjacente a A=0 (haut). On peut grouper les bords opposes.
  • ✅ Faire les groupes les plus grands possible. Un groupe de 4 simplifie plus qu'un groupe de 2.
  • ✅ Un "1" peut appartenir a plusieurs groupes si cela permet d'agrandir d'autres groupes.
  • ❌ Tout "1" doit etre couvert par au moins un groupe.

2.6 — Du Karnaugh au circuit logique

La traduction est directe et mecanique :

Element de l'equationPorte logique
A.B (produit)Porte AND a 2 entrees
A+B (somme)Porte OR
A-barre (variable complementee)Porte NOT suivie de l'entree
S = X + Y + ZOR a 3 entrees (ou 2 OR a 2 entrees en cascade)
💡
Pour S = A.B + A.C + B.C : on a besoin de 3 portes AND a 2 entrees et 1 porte OR a 3 entrees (minimum 4 portes). Sans simplification on aurait eu beaucoup plus de portes.

2.8 — Resume de la methode Karnaugh en 5 etapes

  1. Ecrire la table de verite complete (2^n lignes pour n variables). Calculer S pour chaque combinaison.
  2. Tracer la grille de Karnaugh avec le code Gray (colonnes : 00, 01, 11, 10). Remplir chaque case avec le 0 ou 1 de S.
  3. Identifier les groupes de 1 les plus grands possibles : taille = puissance de 2, formes rectangulaires/carrees, bords toriques. Tout 1 doit etre couvert.
  4. Pour chaque groupe, lire le terme simplifie : garder les variables constantes, eliminer celles qui changent.
  5. Faire la somme (OR) de tous les termes → equation simplifiee finale. Traduire en circuit logique.

Convertisseur Numerique-Analogique (CNA)
Principe · Formules · Reseau R-2R · Quantum

3.1 — Le probleme : passer du numerique a l'analogique

Un microcontroleur ne produit que des niveaux numeriques : 0 V ou 5 V. Or le monde reel est analogique : un moteur a besoin d'une tension variable, un amplificateur audio d'un signal continu... Le Convertisseur Numerique-Analogique (CNA) transforme un mot binaire en une tension analogique proportionnelle.

1011   ⟶   CNA   ⟶   3.4375 V

3.2 — Les formules fondamentales (a savoir par coeur)

Quantum (pas) : q = Vref / 2^n Tension de sortie : Vs = q x N = (Vref / 2^n) x N ou : n = nombre de bits du CNA N = valeur DECIMALE du mot binaire (entre 0 et 2^n - 1) Vref = tension de reference q = le "pas" entre deux niveaux consecutifs (plus petite variation possible)

Comprendre ces formules

  • Un CNA n bits cree 2^n niveaux de tension distincts, numerotes de 0 a 2^n-1.
  • N = 0 → Vs = 0 V. N = 2^n-1 (tous bits a 1) → Vs = Vref x (1 - 2^-n) ≈ Vref mais jamais egal a Vref exactement.
  • Plus n est grand → q plus petit → signal plus "lisse" → meilleure precision.
  • Etape cle avant d'appliquer la formule : convertir le mot binaire en decimal pour obtenir N !

Application numerique : CNA 4 bits, Vref = 5 V

n = 4 bits → 2^4 = 16 niveaux (de 0 a 15) q = 5 / 16 = 0.3125 V (le "pas" ou quantum) Tension max = 15 x 0.3125 = 4.6875 V (et NON 5 V exactement !)

3.4 — Le reseau R-2R : le circuit physique qui realise le CNA

Le circuit le plus elegant pour construire un CNA est le reseau en echelle R-2R. Il n'utilise que deux valeurs de resistances : R et 2R. Pour un CNA 4 bits avec R = 1 kΩ, on n'utilise que des resistances de 1 kΩ et de 2 kΩ.

Principe de cablage :

  • Chaque bit b_i est connecte a une resistance de valeur 2R
  • Le bit vaut "1" → on connecte a Vref (5V). Le bit vaut "0" → on connecte a GND (0V)
  • Les noeuds entre les bits sont relies par des resistances de valeur R
  • Une resistance de terminaison 2R est placee au bout du reseau
  • La tension de sortie Vs est mesuree au dernier noeud
Chaque bit contribue independamment : MSB (b3) → Vs_contribution = Vref/2 = 2.5 V si b3=1 b2 → Vs_contribution = Vref/4 = 1.25 V si b2=1 b1 → Vs_contribution = Vref/8 = 0.625 V si b1=1 LSB (b0) → Vs_contribution = Vref/16 = 0.3125 V si b0=1 Vs totale = somme des contributions des bits a 1
✅
Pourquoi R-2R est superieur aux resistances ponderees : Un CNA a resistances ponderees classique aurait besoin de R, 2R, 4R, 8R... des valeurs qui doublent a chaque bit. Pour 8 bits : R a 128R ! Impossible a fabriquer precisement. Le reseau R-2R n'utilise QUE 2 valeurs, quelle que soit la resolution. C'est pourquoi c'est le circuit le plus utilise en pratique.

3.5 — Exercice type d'examen : calculs CNA

Enonce type

On dispose d'un CNA 8 bits avec Vref = 3.3 V.


Q1. Calculer le quantum q.

q = Vref / 2^n = 3.3 / 2^8 = 3.3 / 256 ≈ 0.01289 V ≈ 12.89 mV

Q2. Quelle tension de sortie pour le mot binaire 0b10110100 ?

Etape 1 — Convertir en decimal : 0b10110100 = 128+32+16+4 = 180 Etape 2 — Appliquer la formule : Vs = q x N = (3.3/256) x 180 ≈ 2.320 V

Q3. Quel mot binaire produit environ 1.65 V ?

N = Vs / q = 1.65 / 0.01289 ≈ 128 (arrondir a l'entier) 128 en binaire 8 bits = 0b10000000

Q4. Combien de niveaux de tension distincts peut-il produire ?

Niveaux = 2^n = 2^8 = 256 niveaux (de 0 a 255 x q)

① Conversions — les points-cles

  • Binaire = base 2, positions = puissances de 2 (128, 64, 32, 16, 8, 4, 2, 1)
  • Dec → Bin : divisions par 2, lire les restes de bas en haut, completer a 8 bits
  • Bin → Dec : sommer les puissances de 2 la ou il y a un 1
  • Bin ↔ Hex : 1 chiffre hex = 4 bits (grouper depuis la droite)
  • A=10, B=11, C=12, D=13, E=14, F=15
  • Prefixes : 0b = binaire, 0x = hexadecimal

② Fonctions logiques — les points-cles

  • 6 portes : NOT, AND, OR, NAND, NOR, XOR → connaitre les tables de verite de memoire
  • Table de verite : 2^n lignes, enumerer toutes les combinaisons, calculer S
  • Equation brute : pour chaque ligne S=1, ecrire le produit de toutes les variables
  • Karnaugh : code Gray (00,01,11,10), groupes en puissances de 2, tableau torique
  • Lire un groupe : constante a 1 → garde, constante a 0 → complementee, change → eliminee
  • Equaton finale = OR de tous les termes → traduction directe en circuit logique

③ CNA — les points-cles

  • Formule unique : Vs = (Vref / 2^n) x N
  • Quantum : q = Vref / 2^n (la plus petite variation possible)
  • N = valeur DECIMALE du mot binaire (convertir le binaire en decimal d'abord !)
  • Reseau R-2R : seulement 2 valeurs de resistances, tres precis a fabriquer
  • MSB contribue Vref/2, bit suivant Vref/4, ..., LSB contribue Vref/2^n
  • Plus n augmente → plus de niveaux → meilleure resolution → signal plus lisse
